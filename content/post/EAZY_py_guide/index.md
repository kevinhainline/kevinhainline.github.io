[EAZY](https://github.com/gbrammer/eazy-py), the photometric redshift code developed by [Gabe Brammer](https://gbrammer.github.io/), is very commonly used in the extragalactic community for its speed and reliability. I've used it for years as a member of [the JADES collaboration](https://jades-survey.github.io/), performing photometric redshift analysis on the catalog sources and [finding ultra-high-redshift galaxies](https://arxiv.org/abs/2601.15959). Over the years, I've talked with many, many folks about the use cases for EAZY, and I decided to collect my thoughts into a website that guides folks through how to run EAZY, update templates and filters, and how to understand the output.  

[You can read my Unofficial EAZY-py guide here.](https://kevinhainline.github.io/eazypy_guide/)

I'm sure there are probably errors and parts that are still confusing. Please let me know if you have any questions!
