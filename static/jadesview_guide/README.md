# JADESView User's Guide

A community-written practical guide to [JADESView](https://github.com/kevinhainline/jadesview) — a software helper to explore the SEDs and thumbnails for JADES sources, alongside EAZY.

🌐 **Live site:** https://kevinhainline.github.io/jadesview_guide/

## About

This guide covers:
- Installation and setup
- How the code works (conceptually)
- JADES catalog and mosaic format requirements
- Parameter file guide
- GUI Parameters and best practices
- Common pitfalls and tips

No build step required. Pure HTML/CSS/JS.
